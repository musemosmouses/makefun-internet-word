# The Internet in One Word

One word for the whole internet: **feral**.

The internet is untamed — unmoderated, unpredictable, every corner wild at
once. Five letters, one beat, funny by itself, true of the whole thing rather
than one app or mood, and not the first obvious word anyone reaches for.

This entry writes exactly `feral` (5 characters, no trailing newline) to
`entry.txt`.

Built for [The Internet in One Word](https://make.fun/c/u-ronigrv-the-internet-in-one-word-e388f33b)
on [make.fun](https://make.fun) — referral: https://make.fun/r/w3zshnah

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

Requires Node 22.18 or later (the grader runs Node 22). Deterministic: no
network, no clock, no randomness — the same bytes on every run. The program
writes exactly the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output`
when the variable is unset), with no trailing newline.
